# Generated material atlas

`kazakhstan-ground-atlas.webp` is the optimized game copy of a material atlas generated with OpenAI's built-in image generation tool on 2026-09-14 for this project. The original PNG is preserved in the local image-generation output directory.

The 4×4 atlas contains fifteen Kazakhstan ground materials in the location order from `src/data/locations.js`, followed by a golden-eagle feather material. The WebP conversion reduces the shipped file from 3.77 MB to about 610 KB for mobile loading.

Generation constraints: top-down orthographic natural materials, flat diffuse light, equal cells, no labels, borders, objects, perspective, or watermarks.
