# Беркутчи

Браузерная 3D-игра о полёте беркута над природными районами Казахстана. Игрок изучает животных, выбирает добычу зорким глазом, выполняет точное пике и возвращается к стоянке. Главная цель — получить 30 знаков мастерства, добраться до Бозжыры и пройти её три испытания.

Опубликованная версия: https://yesetsissenov.github.io/eagle_hunting/

## Что есть в игре

- 15 земель Казахстана: от степи Сарыарки и озёр Кольсай до Чарына, Алтын-Эмеля, Устюрта и Бозжыры.
- Рельеф каждой земли строится из локально сохранённых высот SRTM. Характерные объекты добавляют озёра, затопленный лес Каинды, пойму Или, Поющий бархан, чинк Устюрта и меловые останцы Бозжыры.
- 28 видов животных: 20 видов добычи и 8 охраняемых видов для наблюдения.
- По три испытания в каждой земле: разведка видов, точное скоростное пике и чистое возвращение без столкновений.
- Земли открываются знаками мастерства. Монеты расходуются только на выучку беркута: манёвренность, выносливость и зоркость.
- Прогресс, коллекция, открытия и улучшения сохраняются в `localStorage`.

## Управление

На телефоне левый стик управляет курсом и высотой. Справа находятся отдельные удерживаемые кнопки разгона и пике. «Зоркий глаз» включается одним касанием; после этого животное выбирается касанием по нему на игровом поле.

На компьютере мышь задаёт курс и высоту, `W` или `↑` включает разгон, ЛКМ/`Space`/`S` запускает пике, `V` включает зоркий глаз, `Esc` открывает паузу. В зорком глазе клик по животному берёт его в сопровождение.

## Структура

- `index.html` — маршрут мастера и выбор земли.
- `game.html` — только игровой экран и HUD.
- `collection.html` — коллекция видов, мастерство и выучка.
- `src/core` — прогресс, экономика, хранение и детерминированный случайный выбор.
- `src/data` — единый каталог животных и земель.
- `src/game` — ввод, рельеф, мир, модели, растительность, ориентиры, звук и оверлей.
- `src/ui` — страницы маршрута и коллекции.
- `tests` — модульные проверки контента, экономики, миграции сохранений и математики ввода.
- `scripts` — проверка контента, браузерный smoke-тест и повторная загрузка высот.

Архивная Canvas-версия сохранена в `v2_canvas.html`.

## Локальный запуск и проверки

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev
```

Сайт откроется на `http://localhost:4173`.

```bash
npm test
npm run check
npm run test:browser
```

`npm run check` запускает модульные тесты и проверку целостности трёх страниц, 15 наборов высот и ссылок на животных. Браузерный тест использует установленный Chrome/Chromium: открывает Сарыарку и Бозжыру, проверяет SRTM, мобильный стик и зоркий глаз, затем сверяет коллекцию.

Высоты можно заново получить командой `npm run terrain:fetch`. Источники и лицензии ассетов описаны в `assets/terrain/README.md`, `assets/textures/README.md`, `assets/models/README.md` и `src/vendor/README.md`.
