# Беркутчи — Eagle Hunting 3D 🦅

3D-игра (WebGL / three.js) про охоту с беркутом над Казахстаном. Батыр выпускает птицу — игрок ведёт её прицелом, выслеживает зверьков зорким глазом, берёт в захват, пикирует и приносит добычу. За монеты открываются новые края.

**Играть:** https://yesetsissenov.github.io/eagle_hunting/

Один файл `index.html` + three.js с CDN (нужен интернет). Предыдущая 2D-версия сохранена в `v2_canvas.html`.

## 3D-мир

- Настоящий рельеф с процедурной текстурой земли, трава, кусты, ели и сосны, скалы, юрты — всё объёмное, с тенями от солнца и атмосферным туманом
- Модели: беркут с машущими крыльями и раздельными маховыми перьями, батыр в чапане с орнаментом и тымаке, звери с ушами/хвостами по видам
- Катсцена запуска: камера у батыра, он поднимает беркута на перчатке и выпускает в небо
- Вода: озёра, река, Балхаш; затопленный лес Каинды, клыки Бозжыры, бархан и горы Актау в Алтын-Эмеле, столбы Чарына

## Умное управление

Беркут **летит за прицелом**: веди мышью (или пальцем) — птица сама поворачивает и меняет высоту. Ничего удерживать не нужно.

| Действие | Как |
|---|---|
| Полёт | веди мышью/пальцем — беркут следует за прицелом |
| Разгон | W / ↑ / колесо вверх |
| Пике-атака | зажать ЛКМ / Space / кнопку 🎯 |
| Зоркий глаз | удерживать V / 👁 — подсветка зверьков, замедление, зум |
| Взять в прицел | в зорком глазе кликнуть по зверьку — беркут сам ведёт к цели |
| Меню | Esc / ☰ |
